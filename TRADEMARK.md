# The INNLI name and logo

The code in this repository is open source ([AGPL-3.0](LICENSE), with MIT and GPL parts). Those licences cover the code. They do not give a right to the name "INNLI", the `INN`**`LI`** wordmark or the logo. This page says what you may do with them.

The reason is simple: when a guest, a host or an agent sees "INNLI", they must be able to trust that it is this software, behaving as documented, and not something else under the same name.

## You may, without asking

- Say truthfully that your product or service **works with**, **is built on** or **is compatible with** INNLI.
- Run an unmodified installation for yourself or for a client and call it an INNLI installation.
- Use the name in articles, talks, research, tutorials and reviews.
- Link to this project with the name.

## You need permission to

- Use "INNLI" or something confusingly similar in the name of a product, a company, a hosted service, a domain name or an app.
- Offer a **modified** version under the name INNLI. A fork is welcome, under another name.
- Call a service "the INNLI guide", "INNLI hosting" or "official", or use the logo in a way that suggests it comes from or is endorsed by the project.
- Use the name or logo on merchandise or in advertising.

Running a guide of your own is fine: the code for it is open. Give it your own name and say that it runs on INNLI.

## Asking

Open an issue with the title "Name use", or get in touch through the profile of the owner of this repository. Say what you want to call it and how the name will be shown.

## Status

"INNLI" is used as an unregistered mark by the maintainer of this project. This policy follows the usual practice of open-source projects and does not limit the rights the code licences give you.
