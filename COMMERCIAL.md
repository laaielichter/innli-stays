## When do you need which?

| Situation | Licence |
|---|---|
| You run INNLI for your own B&B, guesthouse or hotel, modified or not | AGPL, free |
| You install INNLI for clients as a web developer | AGPL, free |
| You offer INNLI as a service and publish your modifications under the AGPL | AGPL, free |
| You build INNLI into your own product or service and do **not** want to make your code public (a platform, PMS, channel manager, camper rental platform or agent platform) | **Commercial licence** |
| You want warranties, support or arrangements that the AGPL does not give | **Commercial licence** |

The AGPL requires that anyone who offers a modified version over a network gives the users the source code of that version (section 13). Using an unmodified version is always free: the source code is here.

## What always stays open and permissive

- **The agent-kit** (`agent-kit/`): MIT. Agents and platforms connect without conditions.
- **The WordPress plugin** (`wordpress-plugin/`): GPL-2.0-or-later.
- **The connection itself:** MCP, REST, the passport, the consent hash and the stay wishes. Anyone may implement them in their own software.

## What a commercial licence includes

- The right to build INNLI into a closed product or service, without the AGPL's obligation to publish your own code.
- The same code as the open version: there is no separate closed edition of the software a stay runs itself.
- Every version released during the licence period. You may keep using those versions after the period ends.

**INNLI Pro** comes with the Company licence. It is a separate, closed-source add-on for agent platforms: all-or-nothing trips. An agent plans several stays as one trip, the guest approves one summary, and the requests go out in the order that risks least. If one host says no, the rest is withdrawn. It works with any INNLI installation through the public agent interface.

It does not include support, custom work, hosting or warranties. The software is provided as it is, like the open version.

## What stays free

Running INNLI for your own stay or rental company is free and stays free, with every function in this repository. There is no paid edition for owners, no commission on bookings, no selling of data and no paid places in search results. Money comes from companies that build INNLI into their own closed product.
