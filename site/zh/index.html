// 工作原理

被找到，被读懂，被预订。

被找到、被智能体读懂、真正被预订，是三件不同的事。INNLI 把整条路都铺好。

01 · 护照

事实只需确认一次

约 40 项具体事实：花园是否有围栏、床的长度、到房间有几级台阶、旅游税。每一项都标明已确认、未确认或未知。只有你能确认。

02 · 连接

一个地址，对接所有智能体

智能体查询你的护照、查看实时房态，并拿到包含所有必付费用的分项总价。支持 MCP、REST、ACP 或 UCP。

03 · 预订

直接向你预订，不经中间商

客人同意确切的条款后，房间被保留，由你确认；或者在你设定的规则内即时预订。附带签名记录。

// 一切都遵循的规则

未知的，就保持未知。

靠猜的智能体，会把带狗的客人送到没有围栏的花园。INNLI 从不替你填补空白。

  • 每项事实都有状态、来源和核对日期。满一年后，INNLI 会请你重新核对。
  • 价格要么完整，要么明说不完整。缺少的必付费用会被标出来，而不是藏起来。
  • 结果里没有 booked: true，就不算订上。待处理的请求绝不会被称为预订。
  • 没有隐藏的汇率换算。价格始终以你自己的货币显示。

// 致房东

你的客人，你的价格，你的服务器。

INNLI 可以运行在 Raspberry Pi、你自己的电脑或一台小型服务器上。它不是聊天机器人，也不是又一套酒店系统：它与你现有的网站和预订系统并肩工作。

通过平台
  • 每笔预订抽取 15% 至 22% 的佣金
  • 客人和数据都归平台所有
  • 智能体查不到实时价格，就把客人带去别处
  • 你的房源介绍只能说平台允许说的
使用 INNLI
  • 任何预订都不收佣金
  • 客人数据留在你自己的部署里
  • 来自你的日历或预订系统的实时房态
  • 由你亲自确认的事实，提供四种语言

控制面板

预订请求、客房日历、智能体留下的住宿心愿，以及智能体在你所在地区都在搜什么。提供英语或荷兰语界面。

日历与预订系统

实时预订 API、来自 Airbnb 或 Booking.com 的 iCal、你自己的客房日历，或者只接收请求。防重复预订功能会盯住其他渠道。

WordPress 插件

把你确认过的事实以 schema.org 数据的形式放到你的网站上，为智能体验证你的域名，并管理 AI 爬虫的访问权限。

小型酒店也适用

带库存的房型、价格方案、15 分钟保留、员工密钥，以及发往你 PMS 的签名 Webhook。

防范机器人

限制智能体可保留的房间数量，按智能体、按客人分别计算。你也可以只接受已识别身份的智能体发来的请求。

房车租赁

露营车和自行式房车也能用同样的方式出租：铺位和带安全带的座位、车辆所需的驾照、包含的公里数、押金、取车与还车。智能体会先核对驾驶人，再发出请求。

住宿心愿

客人什么都没找到时，智能体会留下一条匿名心愿。你能看到与你的住宿相符的心愿，并用一份报价来回应。

银行卡担保

可选功能：通过你自己的 Stripe 账户做银行卡担保，预订时预授权，只有你确认后才扣款。

答复助手

根据你确认过的信息和常见问题，立即回答客人的提问。不用语言模型，绝不编造。其余的问题会转给你。
