// 仕組み

見つかる、伝わる、予約される。

見つけてもらうこと、エージェントに正しく理解されること、実際に予約が入ること。この3つは別々の話です。INNLIはその道のりをすべてカバーします。

01 · パスポート

事実の確認は一度だけ

囲いのある庭、ベッドの長さ、部屋までの段差、宿泊税など、約40の具体的な事実。それぞれが「確認済み」「未確認」「不明」のいずれかです。確認できるのはあなただけです。

02 · 接続

すべてのエージェントに、ひとつのアドレス

エージェントはあなたのパスポートを検索し、リアルタイムの空室を確認し、必須費用をすべて含む内訳つきの合計金額を受け取ります。MCP、REST、ACP、UCPに対応しています。

03 · 予約

仲介業者ではなく、あなたに直接予約

ゲストが正確な条件に同意すると部屋が仮押さえされ、あなたが確定します。あるいは、あなたのルールの範囲内で即時予約になります。署名つきの記録も残ります。

// すべてに通じるルール

不明なことは、不明のまま。

推測で答えるエージェントは、犬連れのゲストを柵のない庭に送り込んでしまいます。INNLIが空白を勝手に埋めることは決してありません。

  • すべての事実にステータスがあり、情報源と確認日も記録されます。1年たつと、INNLIが再確認をお願いします。
  • 料金は完全であるか、そうでなければその旨を明示します。必須費用が欠けている場合は、隠さずに知らせます。
  • 結果に booked: true と出ない限り、予約は成立していません。保留中のリクエストを予約と呼ぶことは決してありません。
  • 隠れた通貨換算はありません。料金はあなたの通貨のままです。

// ホストの方へ

あなたのゲスト、あなたの料金、あなたのサーバー。

INNLIはRaspberry Pi、ご自身のPC、または小さなサーバーで動きます。チャットボットでも、新たなホテルシステムでもありません。いまお使いのウェブサイトや予約システムの隣で動きます。

プラットフォーム経由
  • 予約ごとに15〜22%の手数料
  • ゲストもデータもプラットフォームのもの
  • リアルタイムの料金が見つからないと、エージェントはゲストをよそへ案内します
  • 掲載内容は、プラットフォームが許す範囲だけ
INNLIなら
  • どの予約にも手数料はかかりません
  • ゲストのデータは、あなた自身の環境に残ります
  • カレンダーや予約システムからのリアルタイムの空室情報
  • あなた自身が確認した事実を、4言語で

ダッシュボード

リクエスト、客室カレンダー、エージェントから届く宿泊の希望、そしてあなたの地域でエージェントが何を探しているか。英語またはオランダ語で使えます。

カレンダーと予約システム

リアルタイムの予約API、AirbnbやBooking.comのiCal、独自の客室カレンダー、またはリクエストのみ。ダブルブッキング防止機能がほかのチャネルも見張ります。

WordPressプラグイン

確認済みの事実をschema.orgデータとしてサイトに掲載し、エージェント向けにドメインを検証し、AIクローラーのアクセスを管理します。

小さなホテルにも

在庫つきの客室タイプ、料金プラン、15分間の仮押さえ、スタッフ用キー、PMSへの署名つきWebhook。

ボット対策

エージェントが仮押さえできる部屋数を、エージェントごと・ゲストごとに制限します。身元が確認されたエージェントからのリクエストだけを受け付けることもできます。

キャンピングカーレンタル

キャンピングカーも同じ方法で貸し出せます。誰が運転できるか、走行距離、保証金、保険プラン、車両が行ける国。エージェントは依頼の前に運転者とルートを確認し、チェックリストがオーナーに先に整えるべきことを示します。

宿泊の希望

ゲストが何も見つけられなかったとき、エージェントは匿名で希望を残します。あなたの宿に合う希望が表示され、オファーで応えられます。

カード保証

オプションで、あなた自身のStripeアカウントによるカード保証を利用できます。予約時にオーソリを取り、請求はあなたが確定したときだけ行われます。

回答アシスタント

確認済みの情報とFAQをもとに、ゲストの質問にすぐ答えます。言語モデルは使わず、作り話もありません。それ以外の質問はあなたに届きます。
